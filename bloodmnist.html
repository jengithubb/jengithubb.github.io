Blood Cell Classification with Machine Learning & Deep Learning

How much does learning spatial image features help when classifying microscopic blood-cell images? This project compared a Random Forest baseline with a compact PyTorch convolutional neural network on eight BloodMNIST cell categories.

Research question & dataset

The goal was to test whether a compact CNN could outperform a traditional classifier on blood-cell microscopy images, while examining performance across individual cell types rather than accuracy alone. BloodMNIST contains eight categories of preprocessed RGB blood-cell microscopy images. The project used 11,959 training images and 3,421 test images.

Two models, one comparison

01 / Random Forest baseline

Flattened image arrays into feature vectors and fitted a scikit-learn RandomForestClassifier with 100 trees. The model provides a straightforward non-convolutional reference point.

02 / Compact PyTorch CNN

Converted RGB images to tensors, normalized pixel values, and trained a network with two convolutional layers, ReLU activations, max pooling, and two fully connected layers using Adam and unweighted cross-entropy loss.

The CNN improved test accuracy by 7.66 percentage points over the Random Forest baseline, with higher macro-averaged F1 and ROC-AUC. The results demonstrate the value of convolutional representations for this eight-class microscopy image classification task.

What class-level evaluation revealed

High overall accuracy did not mean every cell category was equally easy to recognize. In the CNN classification report, the F1-score was approximately 0.784 for monocytes and 0.798 for immature granulocytes, compared with 0.999 for platelets. This highlights why per-class metrics and error analysis matter in imbalanced biomedical datasets.

Beyond model scores, the comparison illustrates a practical difference between flattened-pixel features and convolutional representations that learn localized visual patterns.

Methods & workflow

  • Prepared image arrays and tensors for model training.
  • Compared traditional machine learning with a compact deep learning architecture.
  • Evaluated accuracy, precision, recall, F1-score, and one-vs-rest AUC, including class-level results.
  • Discussed model capacity, class imbalance, performance trade-offs, and computational efficiency.

Limitations & next steps

This project evaluated performance on a held-out BloodMNIST test set, rather than on external clinical data. Further work could assess performance across additional imaging sources and incorporate repeated seeded experiments, data augmentation and more detailed error analysis.

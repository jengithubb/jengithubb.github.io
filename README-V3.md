# Jennifer Zhu Website V3

Static GitHub Pages website. Upload all files and `assets/` into the repository root, not an enclosing directory. The `.nojekyll` empty file is intentional. Pages: `index.html` and `research.html`, plus the existing `projects.html` and `cv.html`. The original project/CV content was preserved.

**Research privacy:** This version intentionally excludes unpublished results, patient images, specific findings, manuscript files, and exact statistics. Research diagram is illustrative, not research data. Verify all role details and project claims before publishing.

To deploy: copy changed files to GitHub Desktop local repo; Commit; Push; check Settings > Pages that the correct branch root is selected.

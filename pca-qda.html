Breast Tumor Classification with PCA & QDA

Using dimensionality reduction and class-specific covariance modeling to distinguish malignant and benign breast tumors from quantitative cell-nucleus features.

Research question

Can features derived from digitized fine-needle aspirate images distinguish benign from malignant breast tumors? This project evaluated whether principal component analysis (PCA) could reduce redundancy among correlated measurements while providing a stable representation for quadratic discriminant analysis (QDA).

Data and study design

The Wisconsin Breast Cancer Diagnostic dataset contains 569 samples (357 benign and 212 malignant) and 30 numerical cell-nucleus features. These features quantify morphology such as radius, texture, perimeter, area, and smoothness, with different summary descriptors. The reported experiment used an 80/20 training–test split.

Cell morphology

Quantitative measurements from digitized fine-needle aspirate images, rather than raw medical image classification.

Dimensionality reduction

Ten principal components retained over 95% of the reported cumulative feature variance.

The workflow combines PCA, which creates orthogonal components from correlated measurements, with QDA, which models each tumor class using a separate covariance structure. The objective was to retain relevant variation while reducing redundant inputs to the classifier.

Model evaluation

The course report recorded 93.9% overall accuracy and ROC–AUC of 0.991. Class-specific recall was higher for benign than malignant tumors, highlighting why an aggregate score alone is insufficient in a health-related classification task.

The report describes five malignant samples misclassified as benign in the held-out evaluation. This illustrates the importance of examining false negatives alongside accuracy and AUC.

Interpretation and limitations

The project demonstrates how statistical dimensionality reduction and discriminant modeling can be combined in a compact classification workflow. It also illustrates the trade-off between predictive performance and interpretability: principal components reduce correlation but no longer correspond directly to individual biological measurements.

QDA relies on distributional and covariance assumptions, and the modest dataset size limits confidence in generalizability. Independent external validation would be necessary before any clinical application. The reported results are from the course project rather than an externally validated diagnostic system.
